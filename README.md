# MSCS532 Assignment 3: Algorithm Efficiency and Scalability

Python implementations of **deterministic quick sort** and **randomized
quick sort** (Part 1), and a **hash table with chaining** built on a
universal hash family (Part 2), from Cormen, Leiserson, Rivest & Stein,
*Introduction to Algorithms* (4th ed., 2022).

The repository will also contain benchmarks that compare the two quick
sort variants on random, sorted, reverse-sorted, and repeated inputs,
measuring execution time and peak memory.
